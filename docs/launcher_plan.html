DragonRuby Launcher

A small DragonRuby app that holds the SDK, your games and the template in one folder. It lists the games, plays them, runs their tests and makes new ones from the template. It never looks outside its own folder, and the SDK needs no links.

engine DragonRuby 7.23 Standardphases 3tests 16platform Linux only
What I found

The SDK runs a game by its path

./dragonruby takes the game folder as a path, so the link was never required. The launcher builds on that.

Before
cd SDK/dragonruby-linux-amd64
ln -s ../../project-1bit project-1bit
./dragonruby project-1bit
Now
cd launcher/sdk/dragonruby-linux-amd64
./dragonruby ../../projects/project-1bit
  • Hot reload, GTK.write_file and read_file all work in the project's own folder when it's run by path. I checked this with an offscreen run that edited app/main.rb mid-run.
  • GTK.exec runs sh commands from the SDK folder, so the launcher is ../.. and the games are at ../../projects/<name>. It's Ruby backticks and blocks until the output closes, so a game goes to the background with its output sent to /dev/null.
  • --test exits by itself, always with code 0. Only the log says whether tests failed. SDL_VIDEODRIVER=offscreen runs them with no window.
  • A game folder can hold the SDK: ./dragonruby ../.. boots the launcher in under half a second, hot-reloads its own files, and doesn't react to edits inside projects/.
The rule

One folder holds everything

The launcher only looks inside itself. Everything sits at a fixed place, so the code needs no settings and never searches your home folder.

4 app/shell.rb New 22 lines

Every shell command in one place, and the folder rule as three constants: the launcher is ../.. from the SDK and games live in its projects/. The commands are strings, so tests can check them without running anything. QUIET sends a game to the background: GTK.exec is Ruby backticks and waits until the command's output closes, so without it the launcher would freeze until you quit the game.

# The shell commands the launcher runs. The launcher's rule: the SDK lives in launcher/sdk/<sdk>/, where DR runs
# every command, so the launcher's folder is ../.. and games are only looked for in launcher/projects/.
# ./dragonruby takes a game folder by path, so no game needs a link inside the SDK.
module Shell
  HOME     = '../..'                      # the launcher's folder, seen from the SDK
  PROJECTS = "#{HOME}/projects"
  QUIET    = '> /dev/null 2>&1 &'         # in the background, so the launcher keeps drawing

  def self.play name
    "./dragonruby #{PROJECTS}/#{name} #{QUIET}"
  end

  def self.open name
    "xdg-open #{PROJECTS}/#{name} #{QUIET}"
  end

  # Runs a command (logged to the console) and returns what it printed.
  def self.run command
    puts "$ #{command}"
    GTK.exec command
  end
end

class ProjectScene
  attr_dr
  attr_reader :next_scene

  ACTIONS = [{ text: 'Play', action: :play }, { text: 'Open folder', action: :open },
             { text: 'Back', action: :back }].freeze

  # note: a line under the name (what just happened).
  def initialize name, note = nil
    @name, @note = name, note
    @buttons = ACTIONS.each_with_index.map { |b, i| { x: 60, y: 500 - 70 * i, w: 300, h: 56 }.merge(b) }
  end

  def tick
    keys = Controls.down(inputs)
    outputs.labels << Text.label(60, 660, @name, size_px: 48)
    outputs.labels << Text.label(60, 600, @note, Text::GREY) if @note
    button = Buttons.draw(outputs, inputs.mouse, @buttons, keys)
    return @next_scene = ListScene.new if keys[:escape]

    choose button if button
  end

  # What an action button does.
  def choose button
    case button[:action]
    when :play
      Shell.run Shell.play(@name)
      @note = "Started #{@name}"
    when :open then Shell.run Shell.open(@name)
    when :back then @next_scene = ListScene.new
    end
  end
end

2 app/shell.rb Edit +7 lines

Shell.test runs each file with SDL_VIDEODRIVER=offscreen, so All tests doesn't flash 15 windows, then prints DONE at the end. DR always exits with code 0, even when tests fail, so the log is the only way to tell.

# The shell commands the launcher runs. The launcher's rule: the SDK lives in launcher/sdk/<sdk>/, where DR runs
# every command, so the launcher's folder is ../.. and games are only looked for in launcher/projects/.
# ./dragonruby takes a game folder by path, so no game needs a link inside the SDK.
module Shell
  HOME     = '../..'                      # the launcher's folder, seen from the SDK
  PROJECTS = "#{HOME}/projects"
  QUIET    = '> /dev/null 2>&1 &'         # in the background, so the launcher keeps drawing
  HIDDEN   = 'SDL_VIDEODRIVER=offscreen'  # test runs draw offscreen, no window

  def self.play name
    "./dragonruby #{PROJECTS}/#{name} #{QUIET}"
  end

  def self.open name
    "xdg-open #{PROJECTS}/#{name} #{QUIET}"
  end

  # Runs the test files one after another, with no window, into log (a path from the SDK folder), then prints DONE.
  def self.test name, files, log
    runs = files.map { |file| "#{HIDDEN} ./dragonruby #{PROJECTS}/#{name} --test tests/#{file}" }.join('; ')
    "(#{runs}; echo DONE) > #{log} 2>&1 &"
  end

  # Runs a command (logged to the console) and returns what it printed.
  def self.run command
    puts "$ #{command}"
    GTK.exec command
  end
end

4 app/test_log.rb New 18 lines

Reads the log. Each run prints N test(s) passed. and N test(s) failed., plus a **** Test name: Object#… line for each failure.

# Reads the output of DR test runs (one or more --test runs in a row): the totals, the failed tests,
# and whether the runs are over (Shell.test prints DONE at the end).
module TestLog
  PREFIX = '- [Game] '
  FAILED = '**** Test name: Object#'

  def self.summary text
    lines = text.split("\n").map { |line| line.delete_prefix(PREFIX) }
    { passed: count(lines, 'test(s) passed.'), failed: count(lines, 'test(s) failed.'),
      failures: lines.select { |line| line.start_with?(FAILED) }.map { |line| line.delete_prefix(FAILED) },
      done: lines.include?('DONE') }
  end

  # Adds up the "N test(s) ..." lines, one per run.
  def self.count lines, ending
    lines.select { |line| line.end_with?(ending) }.sum(&:to_i)
  end
end

6 app/scenes/tests_scene.rb New 45 lines

The test files plus All tests. The run writes to tmp/test.log in the launcher's folder, Shell::HOME seen from the SDK (the template's .gitignore already skips /tmp/), and the scene reads it again every half second. GTK.write_file creates tmp/ and clears the last run.

# A project's test files, plus All tests. Choosing one runs it in the background; the totals and the
# failed tests show on the right as the log fills. Esc goes back to the project.
class TestsScene
  attr_dr
  attr_reader :next_scene

  ALL = 'All tests'
  LOG = 'tmp/test.log'   # in the launcher's folder

  def initialize name
    @name = name
    @files = Projects.tests(name)
    @buttons = List.buttons([ALL] + @files, 60, 580)
  end

  def tick
    keys = Controls.down(inputs)
    outputs.labels << Text.label(60, 660, "#{@name} tests", size_px: 48)
    button = Buttons.draw(outputs, inputs.mouse, @buttons, keys)
    return @next_scene = ProjectScene.new(@name) if keys[:escape]

    run button[:value] if button
    draw_summary if @running
  end

  # Starts the chosen file (or all of them) writing into LOG.
  def run value
    GTK.write_file LOG, ''   # makes tmp/ and clears the last run
    Shell.run Shell.test(@name, value == ALL ? @files : [value], "#{Shell::HOME}/#{LOG}")
    @running = value
  end

  # What ran, its totals (re-read every half second), and up to 10 failed tests (cut to fit).
  def draw_summary
    @summary = TestLog.summary(GTK.read_file(LOG) || '') if !@summary || Kernel.tick_count % 30 == 0
    x = 880
    outputs.labels << Text.label(x, 580, @running)
    outputs.labels << Text.label(x, 534, @summary[:done] ? 'Done' : 'Running...', Text::GREY)
    outputs.labels << Text.label(x, 488, "#{@summary[:passed]} passed", Text::GREEN)
    outputs.labels << Text.label(x, 442, "#{@summary[:failed]} failed", @summary[:failed].zero? ? Text::GREY : Text::RED)
    @summary[:failures].first(10).each_with_index do |test, i|
      outputs.labels << Text.label(x, 400 - 28 * i, test.delete_prefix('test_')[0, 30], Text::RED.merge(size_px: 22))
    end
  end
end

Shell.create joins the steps with &&, so it stops at the first failure: make the folder (it fails if the name is taken), copy templates/dragonruby-template with tar but without .git and .github, set gameid and gametitle, then git init. It prints CREATED only when every step worked.

# The shell commands the launcher runs. The launcher's rule: the SDK lives in launcher/sdk/<sdk>/, where DR runs
# every command, so the launcher's folder is ../.. and games are only looked for in launcher/projects/.
# ./dragonruby takes a game folder by path, so no game needs a link inside the SDK.
module Shell
  HOME     = '../..'                      # the launcher's folder, seen from the SDK
  PROJECTS = "#{HOME}/projects"
  TEMPLATE = "#{HOME}/templates/dragonruby-template"
  QUIET    = '> /dev/null 2>&1 &'         # in the background, so the launcher keeps drawing
  HIDDEN   = 'SDL_VIDEODRIVER=offscreen'  # test runs draw offscreen, no window

  def self.play name
    "./dragonruby #{PROJECTS}/#{name} #{QUIET}"
  end

  def self.open name
    "xdg-open #{PROJECTS}/#{name} #{QUIET}"
  end

  # Runs the test files one after another, with no window, into log (a path from the SDK folder), then prints DONE.
  def self.test name, files, log
    runs = files.map { |file| "#{HIDDEN} ./dragonruby #{PROJECTS}/#{name} --test tests/#{file}" }.join('; ')
    "(#{runs}; echo DONE) > #{log} 2>&1 &"
  end

  # Copies the template (without its git history and CI) to a new folder, names the game and starts a repo.
  # Prints CREATED when every step worked, else the first error.
  def self.create name, title
    dir = "#{PROJECTS}/#{name}"
    steps = ["mkdir #{dir}",
             "tar -C #{TEMPLATE} --exclude=./.git --exclude=./.github -cf - . | tar -C #{dir} -xf -",
             "sed -i -e 's/^gameid=.*/gameid=#{name}/' -e 's/^gametitle=.*/gametitle=#{title}/' #{dir}/metadata/game_metadata.txt",
             "git -C #{dir} init -q",
             'echo CREATED']
    "(#{steps.join(' && ')}) 2>&1"
  end

  # Runs a command (logged to the console) and returns what it printed.
  def self.run command
    puts "$ #{command}"
    GTK.exec command
  end
end

# The games: every folder in launcher/projects/ (Shell::PROJECTS) with an app/main.rb.
module Projects
  # Game names, sorted, from `ls -d ../../projects/*/app/main.rb` (one path per line).
  def self.parse listing
    listing.split("\n").map { |path| path.delete_prefix("#{Shell::PROJECTS}/").split('/').first }.sort
  end

  def self.scan
    parse Shell.run("ls -d #{Shell::PROJECTS}/*/app/main.rb 2>/dev/null")
  end

  # A game's test files, sorted, from `ls` of its tests folder.
  def self.parse_tests listing
    listing.split("\n").select { |file| file.end_with?('_test.rb') }.sort
  end

  def self.tests name
    parse_tests Shell.run("ls #{Shell::PROJECTS}/#{name}/tests 2>/dev/null")
  end

  # Why a new folder can't take this name (taken = the names already in launcher/projects/), or nil.
  def self.problem name, taken
    "#{name} already exists" if taken.include?(name)
  end

  def self.taken
    Shell.run("ls #{Shell::PROJECTS}").split("\n")
  end

  # A title from a folder name: my_game -> My Game.
  def self.title_for name
    name.tr('_-', '  ').split(' ').map(&:capitalize).join(' ')
  end
end

# A new project from the template: the folder name, then the game's title. Esc goes back to the list.
class NewProjectScene
  attr_dr
  attr_reader :next_scene

  NAME_CHARS  = 'abcdefghijklmnopqrstuvwxyz0123456789_-'
  TITLE_CHARS = "#{NAME_CHARS}ABCDEFGHIJKLMNOPQRSTUVWXYZ "

  def initialize
    @box = TextBox.new('', 24, NAME_CHARS)
  end

  def tick
    outputs.labels << Text.label(60, 660, 'New project', size_px: 48)
    outputs.labels << Text.label(640, 240, @problem, Text::RED.merge(anchor_x: 0.5)) if @problem
    @box.draw(outputs, 640, 400, @name ? 'Game title' : 'Folder name')
    step @box.update(inputs.text, inputs.keyboard.key_down)
  end

  # Enter on the name asks for the title; Enter on the title creates the project.
  def step result
    return @next_scene = ListScene.new if result == :cancel
    return unless result == :done

    @name ? create : take_name
  end

  # Keeps the name if it's free (and suggests a title from it), else asks again.
  def take_name
    @problem = Projects.problem(@box.text, Projects.taken)
    return @box = TextBox.new(@box.text, 24, NAME_CHARS) if @problem

    @name = @box.text
    @box = TextBox.new(Projects.title_for(@name), 32, TITLE_CHARS)
  end

  def create
    out = Shell.run Shell.create(@name, @box.text)
    return @next_scene = ProjectScene.new(@name, 'Created from the template') if out.include?('CREATED')

    @problem = out.split("\n").first
    @box = TextBox.new(@box.text, 32, TITLE_CHARS)
  end
end

class ListScene

  NONE = 'No games in launcher/projects/. Run the launcher from launcher/sdk/<sdk>/ as ./dragonruby ../..'
